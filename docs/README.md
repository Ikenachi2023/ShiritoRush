## 📂 ドキュメント分類規約 (Directory Rules)

│   ├── データベース設計書.md       # 本番環境 データベース設計書 (SQL DDL)
│   ├── オンライン対戦仕様書.md     # 1v1 オンライン対戦同期 ＆ ルームUI仕様書
│   ├── ポイント・レートシステム仕様書.md # ポイント・平均文字数・敗北減点仕様書
│   ├── 単語整合性アルゴリズム.md   # 単語正規化・4層判定ハイブリッドアルゴリズム仕様

    ├── セキュリティ検証レポート.md # XSS/SQLi/パストラバーサル等 セキュリティ安全性検証

## 📜 ドキュメント作成・運用ルール

1. **新規ドキュメント追加時の命名規則**:
   - 種類に応じて `specifications/`, `research/`, `notes/` のいずれかのフォルダに配置すること。
   - ファイル名は内容が明確に伝わる日本語名（例: `単語整合性アルゴリズム.md`）に統一すること。
2. **目次 (`docs/README.md`) の同時更新**:
   - 新しいドキュメントを追加した際は、本 `docs/README.md` の分類一覧へ追記すること。
