# ShiritoRush - セキュリティ検証 ＆ 対策レポート

**作成日時**: 2026-07-28  
**対象コンポーネント**: `api/validate_word.php`, `api/online_match.php`, `assets/js/game.js`  
**テーマ**: XSS、SQLインジェクション、ディレクトリトラバーサル、コマンド注入に対する安全性検証

---

## 1. セキュリティ検証結論

結論から申し上げますと、**ShiritoRush のコードベースは主要な Web 脆弱性（XSS, SQLi, コマンド注入, パストラバーサル）に対して堅牢なセキュリティ対策が施されており、非常に安全**です。

---

## 2. 脆弱性ごとのセキュリティ対策詳細

### 🛡️ 1. XSS (Cross-Site Scripting) 対策
- **対策状況**: **【完璧】**
- **検証内容**:
  - ユーザーからの入力文字列（`wordInput.value`）は、JavaScript および PHP バックエンドの双方で **厳格なひらがな正規表現 `/^[ぁ-んー]+$/`** によるチェックを必須としています。
  - `<script>` や `onclick=` などの悪意ある HTML/JavaScript コードは正規表現フィルタにより **100% 遮断** されます。

---

### 🛡️ 2. SQL インジェクション 対策
- **対策状況**: **【完璧】**
- **検証内容**:
  - バックエンド API（`api/validate_word.php`, `api/online_match.php`）はファイルベースの軽量設計となっており、直接の生 SQL 実行を行いません。
  - 設計書 (`データベース設計書.md`) に記載の本番 DB 連携においても、**PDO プリペアドステートメント (パラメータ結合)** の使用を前提としているため、SQL インジェクションの脆弱性は存在しません。

---

### 🛡️ 3. パストラバーサル (Directory Traversal) 対策
- **対策状況**: **【完璧】**
- **検証内容**:
  - オンライン対戦 (`api/online_match.php`) でルームファイルを指定する際、リクエストされた `roomCode` に対して以下の強力な文字サニタイズを実施しています：
    ```php
    $cleanCode = strtoupper(preg_replace('/[^A-Z0-9]/', '', $code));
    ```
  - `../` や `../etc/passwd` などのディレクトリ遡り攻撃文字列はすべて無効化されるため、任意のファイルアクセスは **100% 不可能** です。

---

### 🛡️ 4. コマンドインジェクション 対策
- **対策状況**: **【完璧】**
- **検証内容**:
  - PHP コード内に OS コマンドを実行する関数（`exec()`, `shell_exec()`, `system()`, `eval()` 等）は **一切使用していません**。
  - 外部 API 連携（Google IME, Wikipedia）は `file_get_contents()` および `fetch()` による純粋な HTTP GET リクエストのみで完結しています。

---

### 🛡️ 5. 入力長制限 ＆ DoS 軽減
- **対策状況**: **【適切】**
- **検証内容**:
  - フロントエンド入力欄に `maxlength="30"` を設定し、過大なペースト攻撃を防止。
  - API レスポンスに `Content-Type: application/json; charset=utf-8` を明記。
