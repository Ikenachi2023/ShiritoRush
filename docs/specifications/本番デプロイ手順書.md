## 1. 本番データベース (DB) 作成指示 ＆ SQL スクリプト

本番環境のデータベース管理ツール（phpMyAdmin, MySQL Workbench, CLI 等）にて、以下の **4つのテーブル** を作成してください。

### SQL DDL (コピペ用)

```sql
-- データベース作成 (任意)
CREATE DATABASE IF NOT EXISTS `shiritorush_db` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE `shiritorush_db`;

-- =========================================================================
-- 1. ユーザーアカウント ＆ レート管理テーブル (users)
-- =========================================================================
CREATE TABLE IF NOT EXISTS `users` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY COMMENT 'ユーザーID',
    `username` VARCHAR(50) NOT NULL UNIQUE COMMENT 'ユーザー名',
    `password_hash` VARCHAR(255) NOT NULL COMMENT 'ハッシュ化パスワード',
    `rating` INT NOT NULL DEFAULT 1500 COMMENT '対戦評価レート (Rate / R)',
    `rank_name` VARCHAR(20) NOT NULL DEFAULT 'SILVER' COMMENT '現在のランク (BRONZE, SILVER, GOLD, PLATINUM, MASTER)',
    `wins` INT NOT NULL DEFAULT 0 COMMENT '勝利数',
    `losses` INT NOT NULL DEFAULT 0 COMMENT '敗北数',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT 'アカウント作成日時',
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX `idx_rating` (`rating` DESC) COMMENT 'ランキング表示用インデックス'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='ユーザーアカウント・レートテーブル';


-- =========================================================================
-- 2. オンライン1v1対戦ルームテーブル (rooms) - 同時複数部屋対応
-- =========================================================================
CREATE TABLE IF NOT EXISTS `rooms` (
    `room_code` VARCHAR(10) PRIMARY KEY COMMENT 'ルームコード (例: RUSH402)',
    `status` ENUM('waiting', 'playing', 'finished') NOT NULL DEFAULT 'waiting' COMMENT 'ルーム状態',
    `host_user_id` BIGINT NOT NULL COMMENT 'ホストユーザーID',
    `current_word` VARCHAR(100) NOT NULL DEFAULT 'しりとり' COMMENT '現在の直前単語',
    `active_player_index` INT NOT NULL DEFAULT 0 COMMENT '現在ターンのインデックス (0 ↔ 1)',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (`host_user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='オンライン1v1対戦ルームテーブル';


-- =========================================================================
-- 3. ルーム参加プレイヤー中間テーブル (room_players - 1v1 最大2名)
-- =========================================================================
CREATE TABLE IF NOT EXISTS `room_players` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `room_code` VARCHAR(10) NOT NULL COMMENT '対戦ルームコード',
    `user_id` BIGINT NOT NULL COMMENT '参加ユーザーID',
    `player_slot` INT NOT NULL COMMENT 'プレイヤースロット (0 または 1)',
    `joined_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY `uk_room_user` (`room_code`, `user_id`),
    UNIQUE KEY `uk_room_slot` (`room_code`, `player_slot`),
    FOREIGN KEY (`room_code`) REFERENCES `rooms` (`room_code`) ON DELETE CASCADE,
    FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='ルーム参加プレイヤーテーブル';


-- =========================================================================
-- 4. 単語提出 ＆ 試合履歴ログテーブル (match_histories)
-- =========================================================================
CREATE TABLE IF NOT EXISTS `match_histories` (
    `id` BIGINT AUTO_INCREMENT PRIMARY KEY,
    `room_code` VARCHAR(10) NOT NULL COMMENT '対戦ルームコード',
    `user_id` BIGINT NOT NULL COMMENT '提出者ユーザーID',
    `submitted_word` VARCHAR(100) NOT NULL COMMENT '入力されたひらがな単語',
    `matched_title` VARCHAR(150) NULL COMMENT '認定タイトル (漢字・カタカナ)',
    `word_length` INT NOT NULL COMMENT '単語の文字数',
    `turn_score` INT NOT NULL COMMENT 'そのターン獲得スコア (pt)',
    `submitted_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX `idx_room_submitted` (`room_code`, `submitted_at`),
    FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='単語提出ログテーブル';
```

## 2. 本番サーバーへデプロイするファイル一覧 (Deployment File List)

本番 Web サーバー（ドキュメントルート `/var/www/html/` 等）へアップロード・配置する必須ファイルの一覧です。

```
ShiritoRush/ (本番公開ディレクトリ)
│
├── index.html                   # メインWebアプリHTML
├── README.md                    # jig.jp インターン選考用ドキュメント
│
├── assets/                      # フロントエンドアセット
│   ├── css/
│   │   └── style.css            # サイバーパンク・ネオンCSSテーマ
│   └── js/
│       └── game.js              # ゲームロジック・1v1オンライン同期JS
│
├── api/                         # バックエンド API エンドポイント
│   ├── validate_word.php        # 4層ハイブリッド単語判定 API
│   └── online_match.php         # 1v1 オンライン対戦同期 API
│
├── data/                        # 辞書データ ＆ ディスクキャッシュ (要: 書き込み権限 777/775)
│   ├── neologd_dictionary.json  # 【最重要】202万語 (2,021,390件) 統合マスター辞書 (111.5 MB)
│   ├── cache/                   # Google IME / Wikipedia 判定一時キャッシュフォルダ
│   └── rooms/                   # オンライン1v1対戦ルーム状態キャッシュフォルダ
│
└── docs/                        # インターン選考用 仕様書・設計書群
    ├── README.md
    └── specifications/
        ├── 仕様書.txt
        ├── API一覧.md
        ├── オンライン対戦仕様書.md
        ├── ポイント・レートシステム仕様書.md
        ├── 単語整合性アルゴリズム.md
        ├── NEologd判定システム仕様書.md
        └── データベース設計書.md
```

### ⚠️ 本番デプロイ時の重要注意事項

1. **`data/neologd_dictionary.json` (111.5 MB)**:
   - このファイルが 202万語の 0ms 超高速オフライン判定のコアとなります。必ず本番サーバーの `data/` 配下にアップロードしてください。
2. **`data/cache/` および `data/rooms/` のアクセス権限**:
   - バックエンド PHP が書き込めるよう、パーミッション `775` または `777` を設定してください。
3. **不要な除外ファイル (デプロイ不要)**:
   - `.git/` フォルダ
   - `scratch/` フォルダ（開発用一時スクリプト群）
