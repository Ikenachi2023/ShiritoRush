## ✨ 機能概要

### 📌 基本機能（課題要件）
- **直前単語の表示 ＆ ターゲット文字ハイライト**: 直前の単語と接続する最後の文字（長音「ー」や小文字の正規化含む）を分かりやすく強調表示します。
- **しりとり接続判定**: 単語の末尾と次の単語の先頭をリアルタイムで照合します。
- **ゲーム終了判定**: 末尾が「ん」で終わる単語や、過去に登場した重複単語が入力された場合、ゲームオーバーとなります。
- **やり直し（リセット）機能**: プレイ中・ゲームオーバー後のいつでもタイトル画面に戻り再スタートできます。

### 🌟 独自機能
1. **辞書 ＋ 4層ハイブリッド単語判定**
   - ブラウザメモリ上のマスター辞書による即時判定をベースに、未登録の言葉は Google IME CGI API と Wikipedia Action API を連携させて高精度に検証します。
2. **🌐 1v1 リアルタイムオンライン対戦**
   - ワンタップで遊べる自動ランダムマッチング、および合言葉による部屋作成・参加機能を搭載しています。
   - 持ち時間3分間の将棋風対局時計、8文字以上の長語による「持ち時間+5秒延長」、スマートフォン（Android等）でのキーボード誤作動防止ロックを備えています。
3. **UI / UX**
   - 視認性を重視したダークガラスモーフィズムデザイン（CSS Vanilla）を採用し、レスポンシブ表示に対応しています。
