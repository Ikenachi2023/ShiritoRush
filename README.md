## ✨ 実装機能およびデザインの詳細説明

### 📌 基本機能（課題要件）
- **直前単語の表示 ＆ ターゲット文字ハイライト**: 直前の単語と、次に接続すべき末尾文字（長音「ー」や「ゃ/ゅ/ょ」等の小文字の正規化含む）をネオンカラーで分かりやすく強調表示します。
- **しりとり接続判定**: 単語の末尾と次の単語の先頭文字をリアルタイムで厳格に照合します。
- **ゲーム終了判定**: 末尾が「ん」で終わる単語や、過去に登場した重複単語が入力された場合、即座にゲームオーバー判定を行います。
- **やり直し（リセット）機能**: プレイ中・ゲームオーバー後のいつでもタイトル画面に戻り、ゲームを再スタートできます。

### 🌟 独自機能
1. **202万語マスター辞書 ＋ 4層ハイブリッド単語判定**
   - インメモリ上の約202万語（2,021,391件）マスター辞書による即時判定（通信不要のハッシュ照合）をベースに、未登録の言葉は Google IME CGI API と Wikipedia Action API を連携させて高精度に検証します。
2. **🌐 1v1 リアルタイムオンライン対戦**
   - ワンタップで遊べる自動ランダムマッチング、および合言葉による部屋作成・参加機能を搭載しています。
   - 持ち時間3分間の将棋風対局時計、8文字以上の長語による「持ち時間+5秒延長」、スマートフォン（Android等）でのキーボード誤作動防止ロックを備えています。
3. **ゲーム性の高いルール・ボーナス**
   - 文字数に応じた基本ポイントに加え、連続投稿によるコンボボーナス（SUPER / MEGA / ULTRA COMBO）、難読・長語ボーナスを実装しています。

### 🎨 デザインコンセプト・演出の詳細
- **ダークガラスモーフィズム (CSS Vanilla)**:
  - 深みのあるダークグラデーション背景と、半透明ガラス調のパネル（`backdrop-filter: blur`）を組み合わせ、洗練されたアーケードゲーム感を表現しています。
- **直感的なレスポンシブレイアウト**:
  - PC・スマートフォンの画面サイズに応じて最適化されるカードレイアウトを採用。Android等の仮想キーボード表示時にも表示崩れを起こさない入力エリア制御を行っています。
- **視認性と演出**:
  - タイマーやターン状態（「⚡ あなたのターン」「⌛ 相手のターン」）を分かりやすく色分け表示し、スコア加点時のポップアップ演出等でゲームの臨場感を高めています。

## 🔗 参考にしたWebサイト

本プロダクトの開発および単語検証システムの構築にあたり、以下のWebサイト・API仕様書・リポジトリを参考にいたしました。

1. **Wikipedia Action API (MediaWiki)**
   - [MediaWiki API: Main page/ja (Wikipedia Action API 仕様書)](https://www.mediawiki.org/wiki/API:Main_page/ja)
   - *活用内容*: 未登録単語や固有名詞（映画タイトル・作品名等）の存在確認および正式タイトルの検証に使用。
2. **Google IME CGI API**
   - [Google 日本語入力 CGI API 開発者ガイド](https://www.google.co.jp/ime/cgiapi.html)
   - *活用内容*: ひらがな入力に対する漢字・カタカナ変換候補の第一候補取得および単語実在性の一次検証に使用。
3. **mecab-ipadic-NEologd (語彙マスター辞書データ)**
   - [github.com/neologd/mecab-ipadic-neologd](https://github.com/neologd/mecab-ipadic-neologd)
   - *活用内容*: 新語・固有名詞・映画タイトル・基本語彙を含む約202万語のマスター辞書データの生成・抽出元として活用。
4. **jig.jp サマーインターンシップ 2026 課題要項**
   - [jig.jp summer 2026 assignment](https://jigintern.github.io/summer-2026-assignment/)
   - *活用内容*: 基本課題要件・提出形式の確認に使用。

## 🤖 AIツールの活用について

本課題の制作にあたっては、**Google Antigravity Agentic AI** をパートナーとして全体的に活用いたしました。

### AIの具体的な活用内容
- **仕様と指示に基づくコード記述**: 提示した仕様書および開発指示に基づき、HTML/CSS/JavaScript/PHPのコード記述を実施しました。
- **プロジェクト全体**: 設計・実装・デバッグ・リファクタリング・ドキュメント作成に至る全工程でAIを活用しました。
- **情報検索および調査レポートの作成**: Wikipedia API・Google IME API・語彙判定アルゴリズム等に関する技術情報の検索と、`docs/` 配下の各種調査レポートの作成を主として活用いたしました。
